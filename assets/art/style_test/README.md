# Style test (generated)

Made by `tools/pixelart/style_test.py`. Run it again after editing to regenerate everything.

- `mockup_1920x1080.png`: the lit test scene as it would look on a 1080p screen.
- `mockup_detail_x3.png`: a close-up, to judge the pixel work.
- `sheet_x4.png`: every sprite, 4x.
- `palette.gpl`: the palette. Open it in Aseprite (Palette > Load) to draw with the same colours.
- `tiles/`, `props/`, `chars/`: individual sprites, each with a `_n.png` normal map for lighting.
